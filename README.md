# LITOR Surf Widget

LITOR Surf Widget é um aplicativo iOS simples para surfistas, projetado para fornecer informações diárias essenciais de surf diretamente na tela inicial do iPhone. O app se concentra em uma interface minimalista, elegante e costeira, alinhada à identidade visual da marca LITOR.

## Objetivo
Criar um painel diário de surf que mostre:
- Condição geral (ruim, regular, bom, clássico)
- Nota de surf de 0 a 10
- Altura, período e direção da ondulação
- Intensidade e direção do vento
- Maré atual e tendências
- Melhor janela do dia para surfar

## Tecnologias
Este projeto utiliza:
- **Swift** e **SwiftUI**
- **WidgetKit**
- Arquitetura MVVM

## Funcionalidades
- [x] Widget grande para a tela inicial
- [x] Tela de configuração do pico favorito e unidades
- [x] Dados mockados para desenvolvimento inicial

## Como usar
1. Abra o projeto no **Xcode**.
2. Simule no dispositivo ou no emulador (requer iOS 14+).
3. Adicione o widget à tela inicial.
